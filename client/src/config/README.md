# SEO Config

The Search Engine Configuration (SEO) file consist of application data used for managing application's SEO.

SEO is important for the application as it helps exposes its information to be public when searched.

The SEO Config contains the following:

1. Site Name: Domain name (The registered application name)
2. Site Url: The unified resource location of the address
3. Site Description: A description of the project/application of the organization
4. Site Image:
5. Facebook Page:
6. Email
7. Phone
8. Address
9. Pages: All pages included with the following page properites:
  - title: Page title
  - description: Page description
  - keywords: Page keywords
  - image: Page images
