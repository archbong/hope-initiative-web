# Application Data

Contained in this directory are the data used in this application.

1. `events.json`
    A json representation of events data for the application
    The representation consist of the following:
    - id: Identification number
    - slug: Event slug
    - title: Event title
    - description: Event description
    - content: Content of the event
    - data: Event date
    - endDate: Event end date.
    - location: Event location/venue
    - category: Event category
    - type: Event type
    - image: Event image
    - thumbnail: Event thumbnail
    - author: Event author
    - readTime: Time it takes to read
    - featured: Is it's featured?
    - status: Event status
    - registrationLink: Navigate users to registration link
    - contactEmail: Event email contact
    - contactPhone: Event phone contact
2. `gallery.json`
    A json representation of events data for the application
    The representation consist of the following:
3. `partner.json`
4. `programs.json`
5. `stories.json`
