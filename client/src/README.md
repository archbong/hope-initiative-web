# Source Directory Information.

- Assets
  * This holds the images of this projects (currently empty)
- Components
  * This holds the buiding blocks of the application. This directory has it's own `README.md` for more information.
- Config
  * App configs are stored here. This directory has it's own `README.md` for more information.
- Constants
  * Constants are stored here. This directory has it's own `README.md` for more information.
- Data
  * This holds static data for dynamic consumption. This directory has it's own `README.md` for more information.
- Hooks
  * Hooks for comsuming data are stored here. This directory has it's own `README.md` for more information.
- Interface
  * All application interface are defined here. This directory has it's own `README.md` for more interface information.
- Pages
  * All pages are located in this directory. This directory has it's own `README.md` for more information.
- Services
  * All services are located in this directory. This directory has it's own `README.md` for more information.
- Types
  * Data types can be found here. This directory has it's own `README.md` for more information.
- Utils
  * Helpers are located here. This directory has it's own `README.md` for more information.
- App.css
  * This file is empty as the project styling properties are all in `index.css`.
- App.tsx
  * `App.tsx` holds in its all the routes of the pages. All routes are configured here.
- index.css
  * `index.css` holds all the styles properties applied to the application. 
- main.tsx
  * This is the entry file of the application.
