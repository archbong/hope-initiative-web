# Components information

This document provides information contained in this `components` directory.

Below are the following components and what they contain

- layout
   The Project's/Application's layout directory contains the following files:
  1. `Footer.tsx`
      This file holds the snippet for the footer of this application. To make any changes on the footer, locate this file.
  2. `Layout.tsx`
      This file holds the snippet for the layout of this application. To make any adjustment to the layout, locate this file
  3. `Navbar.tsx`
      This file holds the snippet for the navigation menu of this application. You can make any changes on the navbar here.
- SEO
  This file hold the Search Engine Optimization (SEO) for this application. All SEO configuration can be done here. The directory holds two components:
  1. `SEOhead.tsx`
      This file contains a reusable SEO component for all pages as the head
  2. `SEOSchema.tsx`
      This file contains the SEO Schema.
- ui
  This file contain ui components for reusability across application. It contains the following files
